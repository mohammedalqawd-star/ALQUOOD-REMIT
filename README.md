# ALQUOOD REMIT

تطبيق مستقل لإدارة العملاء والحوالات، منفصل عن ALQUOOD Pay.

## المزايا الحالية
- لوحة إحصائيات وإجمالي منفصل حسب العملة.
- دخول مدير وموظفين محليًا مع صلاحيات مختلفة.
- اعتماد أو تغيير حالة الحوالة من المدير مع تسجيل العملية.
- سجل نشاط يشمل تسجيل الدخول والعمليات المهمة.
- حماية من إيقاف آخر حساب مدير نشط.
- إيصال نصي قابل للنسخ والطباعة بعد لصقه في مستند.
- تصدير بيانات العملاء والحوالات بصيغة CSV.

## ما تتضمنه النسخة التأسيسية
- ملفات العملاء: الاسم، الهاتف، الهوية، العنوان، رقم الحساب.
- تسجيل الحوالات: الرقم المرجعي، المرسل، المستلم، هاتف المستلم، المبلغ، العملة، الحالة، التاريخ والملاحظات.
- البحث في العملاء والحوالات.
- كشف الحوالات المرتبطة بالعميل.
- حفظ محلي باستخدام SQLite ويعمل دون إنترنت.

## التشغيل
يتطلب Flutter SDK:
```bash
cd mobile
flutter pub get
flutter run
```

## بناء APK
كل push إلى main يشغّل GitHub Actions لبناء APK ويرفعه كـ artifact باسم `alquood-remit-apk`. افتح تبويب Actions ثم آخر تشغيل ناجح لتنزيله.

## تنبيهات
هذه نسخة أولية وليست نظامًا مصرفيًا معتمدًا. لا تستخدم بيانات حقيقية قبل مراجعة الأمان والنسخ الاحتياطي. إرسال WhatsApp وSMS والمزامنة السحابية غير مفعّلة بعد، وتتطلب مزودًا رسميًا وإعدادًا آمنًا. لا تضع بيانات العملاء أو مفاتيح API في المستودع.
